# 坦克大乱斗（diep-solo-cn）

> **单机特化版** diep.io —— 为一个人游玩深度改造：**每一个模式都有 AI 坦克手陪你打**，所有增益只对真人玩家生效，全中文界面（含坦克图鉴 / 进化树 / 成就），支持手机 / 平板触屏。

基于开源项目 [diepcustom](https://github.com/abcxff/diepcustom)（AGPL-3.0）二次开发。

---

## 这是什么

| | 原版 diepcustom | 本项目（单机特化） |
|---|---|---|
| 玩法 | 多人联网，等真人凑局 | **单机即玩**，每个模式都注入 AI |
| 模式 | 官方 10 个模式，多数要凑人数 | 10 个模式全部可直接开局，无等待 |
| AI | 仅测试用途 | 40 台 AI 坦克手：五流派（强攻 / 风筝 / 铺场 / 无人机 / 撞击）、三难度、每局随机配额 |
| AI 行为 | — | 会发育（主动找方块）、会打架（按流派卡距离）、**会追击视野内残血**、残血会撤退回血再战 |
| 回合 | 无 | 30 分钟一局 → 清场者合围 → 全员等级清零开新局，底部有**清场倒计时条** |
| 界面 | 英文 | 全中文（WASM 内存级汉化 + 中文覆盖层），模式列表也全中文 |
| 地图 | 22300（原版） | 同原版大小，方块密度按面积缩放 |
| 联网 | — | **完全离线单机**，不连任何官方服务器 |

## 一键启动（Windows）

双击根目录 **`启动游戏.bat`**：

1. 首次运行自动安装依赖并构建（约 1~2 分钟）；
2. 自动启动本地服务器（端口 **8180**）；
3. 自动打开浏览器进入游戏，默认进入"坦克大乱斗"。

停止：任务栏关闭 `diep-server` 窗口。

需要 Node.js（建议 18+）；构建产物在 `game/diepcustom/lib/`。

## 快捷键

### 移动与战斗（与原版 diep.io 相同）

| 按键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 瞄准 |
| 鼠标左键 | 开火 |
| 鼠标右键 | 无人机系回收（repel）；其余坦克无副作用 |
| `1` ~ `8` | 加点（对应 8 项属性） |
| `Enter` | 出生 / 复活确认 |

### 本项目新增 / 强化

| 按键 | 作用 |
|---|---|
| `L` | **打开 / 关闭单机设置菜单**（见下）；正在输入名字时不触发 |
| `K` | 升 1 级（**按住连升**，原版作弊键） |
| `O` | 自杀（死亡后可配合右下角复活按钮重新开始） |

### 界面按钮（右下角工具栏）

| 按钮 | 作用 |
|---|---|
| 图鉴 | 48 辆坦克中文介绍 + 分类 + 进化链 |
| 进化树 | 五大系分支中文视图 |
| 加点 | 属性说明 + 一键加点（发送标准协议包，服务端校验） |
| 设置 | 同 `L` 键 |

### 死亡 / 复活助手（死亡界面右下角自动弹出）

| 按钮 | 作用 |
|---|---|
| 复活（保留等级） | 保留完整等级与加点原地重来 |
| 重新开始（清零等级） | 等级 / 加点清零，从 1 级开始 |

## 单机设置菜单（`L` 键）

游戏中按 `L` 实时调整，**改完立即生效**，且**只对真人玩家生效**——AI 的同职业坦克上限不受影响：

| 设置项 | 说明 |
|---|---|
| 无人机数量上限倍率 | 0.5~10 倍，作用于所有无人机系 / 工厂兵（如霸主 8 机 ×3 = 24 机），支持 ± 按钮或直接输入 |
| 死灵法师每管上限 | 0 = 原版公式（11 + 装填等级），设为数字则直接覆盖 |
| 三角形转化 | 死灵法师击杀**三角形**也复活成无人机（血量 / 攻击约 ×6） |
| 五边形转化 | 击杀**五边形 / 超大五边形**也复活成无人机（血量 / 攻击约 ×9） |

> 转化无人机的血量与攻击力按被吞方块的伤害比例自动放大（方块 ×4 / 三角 ×6 / 五边 ×9）。三角与五边转化**默认开启**，服务器启动即为开。设置存于服务器内存，重启恢复默认。

## 模式与 AI

全部 10 个模式均注入 AI（默认 40 台，可用环境变量 `BOT_COUNT=数量` 调整）：

- **坦克大乱斗**（默认模式）：1 真人 + AI 大乱斗 + 30 分钟回合清场循环
- 自由乱斗 / 迷宫 / 沙盒：各自为战
- 双队 / 四队 / 占领 / 捉人 / 母舰：AI 自动随机分队；真人所在队伍获胜才结束回合，AI 之间打完自动开新局
- 生存：AI 也计入缩圈与开局人数，真人阵亡后本局提前结束并快速开新一局

## 目录结构

```
diep-solo-cn/
├── 启动游戏.bat                # 一键启动
├── docs/                       # 设计稿与执行计划
│   ├── diepio-单机AI版设计稿.md
│   └── diepio-执行计划.md
└── game/diepcustom/            # 游戏服务端 + 客户端（全部改造在此）
    ├── client/                 # 客户端
    │   ├── loader.js           # WASM 加载 + 内存级中文汉化 + 成就 JSON 替换
    │   ├── overlay/            # 中文覆盖层（图鉴/进化树/加点/设置菜单/复活助手/倒计时条）
    │   ├── ach_zh.js           # 中文成就数据（与服务端 hash 一致）
    │   └── touch.js            # 手机/平板双摇杆触屏适配
    └── src/                    # 服务端
        ├── Gamemodes/          # 10 个模式（全部注入 AI + 中文模式名）
        ├── Entity/AI/          # BotSpawner / BotManager / BotBrain（流派 + 难度行为层）
        ├── soloSettings.ts     # 运行时设置（L 键菜单后端）
        └── Const/TankDefinitions.json  # 坦克定义（全中文命名与属性名）
```
